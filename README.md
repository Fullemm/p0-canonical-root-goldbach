# Canonical-Root Goldbach Research

This repository contains the research master document for an experimental
program concerning a deterministic factor-search rooted at

p0(N) = min { p prime : p >= N/2 }.

## Status

- Binary Goldbach conjecture: OPEN
- Universal canonical-root traversal success: CONJECTURE
- The master document contains proved results, computational results,
  conjectures, failed approaches, superseded arguments, and research logs.

The master PDF is a research knowledge base intended for humans and AI
research systems. It is not a proof of the Goldbach conjecture and should
not be read as a single publication-quality argument.

A separate research article describing the canonical-root algorithm,
computational experiments, and root-ablation results is available on Zenodo:
https://zenodo.org/records/22551656
